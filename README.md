# COSMIC BROTH

Vue 3 + Vite recreation of [cosmicbroth.com](https://www.cosmicbroth.com/) for study.

**Live:** https://xiaoqianran.github.io/web-002-Space/

Content (c) original authors: 万能翻译器 (novel) / 真实伪色 (art).

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173

Data loads from `/public/data` JSON first (offline), then live API fallback.

## Deploy

Pushes to `main` build with `BASE_PATH=/web-002-Space/` and publish via GitHub Actions to GitHub Pages.
